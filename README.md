# TicMouse UIプロトタイプ 0.3（C案ハイブリッド、円弧レイアウト＋計器風デザイン）

作成: 2026-11-11 / 対象機: TicWatch Pro 5 Enduro（Wear OS 4.0）＋ Pixel 9a
パッケージ: com.example.ticmouseproto / minSdk 30 / targetSdk 33 / デバッグ署名
APK: `ticmouse-proto.apk`（このフォルダ直下）

## これは何か（正直な内訳）
- **本物**: Wear OSネイティブの実アプリ。C案の画面とタッチ操作が実際に動く
  - レイアウト v0.3（2026-11-11 ユーザー指定）: 中央ハイブリッドは直径65%で画面中央。
    その外側の輪を120°ずつ3等分し、左上＝左クリック／右上＝右クリック／下＝情報ゾーン。
    クリック判定は中央に覆われていない部分だけ（中央が上レイヤー）
  - デザイン v0.3: グラファイト基調の計器風（派手すぎず機械的・未来感）。
    左クリック＝濃いグレー緑／右クリック＝濃いグレー青の塗りつぶし、
    ボタン類は落ち影＋上端ハイライト＋上下グラデーションで立体感。
    レーダー文字盤は実装基盤のみで、デザインは引っ張られていない
  - クリック: タップ、左2回押し＝ダブルクリック、長押し＝ドラッグ状態、バイブ通知
  - 中央: ハイブリッド操作部。外周リング＝十字（タップ1ステップ、長押しリピート＋加速）、
    中央ノブ＝レバー（倒す量の2乗で速度変化、デッドゾーン8%、離すと中央に戻る）
  - 同時タッチ対応（クリックを押しながらレバーを動かせる想定の判定）
  - 下部セクター: 中央にイベント表示、左下に LOCAL 表示、右下タップでスクロール切替
    （ON中はレバーの上下／リング上下がスクロールになる）
  - 下部セクターを長押し（0.6秒）→ テストパネル: HID登録テストボタン付き
- **デモ（仮）**: 画面内の照準カーソルはこのアプリの中だけで動く仮ポインター。
  スマホ／PCへの送信はまだしていない。接続表示「LOCAL」は表示のみ
- **未検証**: 実機でのレイアウト・操作感・HID登録の可否はこれから。
  このVMではエミュレーター実行はしておらず、確認したのはビルド成功・署名検証・
  パッケージ情報（aapt2 dump）のみ

## HID登録テストの見方
テストパネルで「HIDテスト」を押す → Bluetooth権限を許可 →
「登録成功！ OS4でもHID可」と出れば、この実機＋Wear OS 4.0で
PC向けHID方式が使える見込みが立つ。出なければ PC向けは
旧方式（WebSocket＋PC側Pythonホスト）へ切り替える判断材料になる。
※このテストは登録の可否だけを見るもの。PCとペアリングして
カーソルを動かすところまでは行わない。

## 実機への入れ方（無線ADB／Wear Installer 2 が本命。2026-11-11 ユーザー希望）
前提: Pixel 9a と時計が同じWi-Fi。時計のWi-Fiは「自動」ではなくONにして接続しておく。
APKは Pixel 9a の Download フォルダに保存しておく。

1. 時計: 設定 → システム → デバイス情報 → ビルド番号を7回タップ（開発者オプション有効化）
2. 時計: 開発者オプション → ADBデバッグ ON → ワイヤレスデバッグ ON。
   「このネットワークでは常に許可」にチェックして許可。表示される IPアドレスを控える
3. Pixel 9a: Play ストアで Wear Installer 2 を入れて開き、時計の IPアドレスを入力 → Done
4. ペアリング（Wear OS 4 の必須手順・初回のみ）:
   WI2 の右上メニュー →「Pair with watch」→ Enable。
   時計側: ワイヤレスデバッグ →「新しいデバイスをペアリング」で表示される
   6桁コードとペアリング用ポートを、WI2 に「コード<半角スペース>ポート」
   （例: 364074 34575）と入力 → Done
5. 時計のワイヤレスデバッグ画面に戻ると、IP の後に新しい5桁ポート（接続用）が出る。
   それを WI2 のホーム画面の IP の横の欄に入力 → Done
   ※ ペアリング用ポートと接続用ポートは別物。ここが一番間違えやすい
6. WI2:「Custom APK」→ Download フォルダの ticmouse-proto.apk を選択 → Install
7. 時計のアプリ一覧から「TicMouse Proto」を起動
8. 終わったら時計の ADBデバッグ／ワイヤレスデバッグは OFF に戻す（電池と安全のため）

代替: PC がある場合は `adb pair` → `adb connect` → `adb install ticmouse-proto.apk` でもよい。
